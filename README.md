# qa_python Проект по Юнит-Тестам

## Сколько тестов и как именно удалось реализовать:
Удалось реализовать 9 тестов. 1 из них параметризованый на 2 варианта данных. То есть итого 10 тестов.
Также были использованы фикстуры c областью видимости в рамках функции (по умолчанию).

## Какие конкретно тесты были проведены:
* Проверили добавление 2х новых книг
* Проверили установку жанров двум книгам
* Проверили получение жанра книги по её имени
* Проверили вывод списка книг с определённым жанром
* Проверили получение словаря books_genre со всеми книгами в нём
* Проверили возвращение списка книг, подходящих детям
* Проверили добавление книги в Избранное
* Проверили получение списка Избранных книг
* Проверили удаление книги из Избранного
